# Inhouse Thumbnail

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/thumbnail

# or

$ yarn add @pepabo-inhouse/thumbnail
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Thumbnail コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/thumbnail/)を参照してください。
