# Inhouse Sticker

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/sticker

# or

$ yarn add @pepabo-inhouse/sticker
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Sticker コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/sticker/)を参照してください。
