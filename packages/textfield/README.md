# Inhouse Textfield

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/textfield

# or

$ yarn add @pepabo-inhouse/textfield
```

## デザインドキュメント (Design Documentation)

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Textfield コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/textfield/)を参照してください。
