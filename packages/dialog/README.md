# Inhouse Dialog

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/dialog

# or

$ yarn add @pepabo-inhouse/dialog
```

## デザインドキュメント (Design Documentation)

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Dialog コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/dialog/)を参照してください。
