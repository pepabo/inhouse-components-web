# Inhouse Radio

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/radio

# or

$ yarn add @pepabo-inhouse/radio
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Radio コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/radio/)を参照してください。
