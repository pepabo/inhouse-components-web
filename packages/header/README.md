# Inhouse Header

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/header

# or

$ yarn add @pepabo-inhouse/header
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Header コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/header/)を参照してください。
