# Inhouse Checkbox

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/checkbox

# or

$ yarn add @pepabo-inhouse/checkbox
```

## デザインドキュメント (Design Documentation)

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Checkbox コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/checkbox/)を参照してください。
