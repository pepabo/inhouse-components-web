# Inhouse Container

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/container

# or

$ yarn add @pepabo-inhouse/container
```

## デザインドキュメント (Design Documentation)

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Container コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/container/)を参照してください。
