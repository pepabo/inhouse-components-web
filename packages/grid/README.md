# Inhouse Grid

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/grid

# or

$ yarn add @pepabo-inhouse/grid
```

## デザインドキュメント (Design Documentation)

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Grid コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/grid/)を参照してください。
