# Inhouse Callout

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/callout

# or

$ yarn add @pepabo-inhouse/callout
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Callout コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/callout/)を参照してください。
