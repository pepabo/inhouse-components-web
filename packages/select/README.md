# Inhouse Select

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/select

# or

$ yarn add @pepabo-inhouse/select
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Select コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/select/)を参照してください。
