# Inhouse Navigation Drawer

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/navigation-drawer

# or

$ yarn add @pepabo-inhouse/navigation-drawer
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Navigation Drawer コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/navigation-drawer/)を参照してください。
