# Inhouse Interactive Table

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/interactive-table

# or

$ yarn add @pepabo-inhouse/interactive-table
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Interactive Table コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/interactive-table/)を参照してください。
