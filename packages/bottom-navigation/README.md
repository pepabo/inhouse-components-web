# Inhouse Bottom Navigation

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/bottom-navigation

# or

$ yarn add @pepabo-inhouse/bottom-navigation
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Bottom Navigation コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/bottom-navigation/)を参照してください。
