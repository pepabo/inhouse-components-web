# Inhouse Skeleton

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/skeleton

# or

$ yarn add @pepabo-inhouse/skeleton
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Skeleton コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/skeleton/)を参照してください。
