# Inhouse Validation Message

## Usage

### Installation

```bash
$ npm install @pepabo-inhouse/validation-message

# or

$ yarn add @pepabo-inhouse/validation-message
```

コンポーネントの使い分け・バリエーション・ステート・アクセシビリティ・ライティングの規約は、[Pepabo Design の Validation Message コンポーネントのドキュメント](https://design.pepabo.com/inhouse/components/validation-message/)を参照してください。
